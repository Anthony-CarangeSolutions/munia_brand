# 03 — Logo

## Composition

Le logo Munia est composé de deux éléments :

1. **Le symbole** — une marque graphique abstraite construite autour d'une forme inspirée de la convergence (carré, point central, ouverture vers le haut). Elle évoque la rencontre entre une municipalité et l'intelligence.
2. **Le wordmark** — le mot *Munia* en typographie GT Standard.

Les deux peuvent être utilisés ensemble (logo complet) ou séparément (symbole seul comme avatar / favicon).

## Variantes disponibles

| Code fichier | Description | Usage typique |
|---|---|---|
| `logo-rect-black` | Logo complet horizontal, noir sur fond clair | Documents, en-têtes, sites web fond blanc |
| `logo-rect-white` | Logo complet horizontal, blanc sur fond foncé | Présentations sombres, fond noir |
| `logo-rect-black-bg` | Logo complet horizontal, fond noir intégré | Carte de visite, signature, cadre dédié |
| `logo-rect-white-bg` | Logo complet horizontal, fond blanc intégré | Sur photos / fonds chargés |
| `logo-sqr-black` | Format carré, noir | Avatars LinkedIn, profils sociaux |
| `logo-sqr-white` | Format carré, blanc | Avatars sur fond foncé |
| `logo-sqr-*-bg` | Format carré avec fond | Tuiles, vignettes |
| `Symbole_final_Munia` | Symbole seul (sans wordmark) | Favicon, watermark, app icon |

## Formats fournis

- **SVG** — usage web et impression vectorielle (privilégier ce format).
- **PNG** — usage rapide, transparence supportée.
- **JPG** — usage limité (pas de transparence).
- **EPS** — usage impression professionnelle.

Tous les fichiers sont dans `assets/logo/`.

## Règles d'usage

### À faire
- Toujours conserver les **proportions** d'origine.
- Respecter une **zone de protection** autour du logo équivalente à la hauteur de la lettre « M ».
- Choisir la version (noir / blanc) selon le **contraste** avec le fond.
- Utiliser le **SVG** dès que possible.

### À éviter
- Ne **pas déformer** (étirement, écrasement).
- Ne **pas changer les couleurs** du logo (utiliser uniquement noir, blanc, ou les versions fournies).
- Ne **pas ajouter d'effets** (ombre, dégradé, contour) au logo.
- Ne **pas placer** le logo sur un fond peu contrasté ou chargé sans la version `*-bg`.
- Ne **pas reproduire** le logo manuellement (toujours utiliser les fichiers fournis).

## Tailles minimum

- **Web** : symbole ≥ 32 px, logo complet ≥ 120 px de large.
- **Impression** : symbole ≥ 10 mm, logo complet ≥ 25 mm de large.

En dessous de ces tailles, privilégier le **symbole seul**.
